# Retail Sales SQL Project

## Project Overview
This project analyzes retail sales data using SQL Server to identify sales trends, customer purchasing behavior, and product performance.

## Tools Used
- SQL Server Management Studio (SSMS)
- SQL

## Dataset
- Customers
- Products
- Orders
- OrderItems

## SQL Concepts Practiced
- SELECT, WHERE, ORDER BY
- Aggregate functions and GROUP BY
- Joins and subqueries
- Common Table Expressions (CTEs)
- Window functions and ranking
- Running totals and monthly revenue growth

## Business Questions
## Level 1: Basic SQL (1–5)
1. Total Orders: How many orders have been placed?
2. Customer Analysis: List all customers from Chennai.
3. Product Pricing: Find products priced above ₹1,000.
4. Order Status: Count the orders in each status, such as Delivered, Pending, and Cancelled.
5. Product Categories: Count the number of products in each category.

## Level 2: Intermediate SQL (6–10)
7. Total Revenue: Calculate total revenue from all order items using quantity × unit price.
8. Top-Selling Products: Find the top 5 products by total quantity sold.
9. Customer Spending: Calculate total spending for each customer.
10. City Performance: Find total revenue generated by each city.
11. Average Order Value: Calculate the average order value.

## Level 3: Joins and Subqueries (11–15)
13. Inactive Customers: Find customers who have never placed an order.
14. High-Value Customers: Find customers whose total spending is above the average customer spending.
15. Products Never Ordered: Identify products that have never appeared in an order.
16. Top 3 Customers: Find the three customers who spent the most.
17. Above-Average Orders: Find orders whose value is greater than the average order value.
    
## Level 4: Advanced SQL (16–20)
19. Second-Highest Price: Find the second-highest distinct product price.
20. Category Ranking: Rank products by price within each category.
21. Running Revenue: Calculate cumulative revenue over time.
22. Monthly Sales Growth: Calculate monthly revenue and its percentage growth compared with the previous month.
23. Customer Order Frequency: Find customers who placed at least three orders.
    
## Level 5: Real-World Business Analysis (21–25)
25. Best-Selling Product by Category: Identify the product with the highest total quantity sold in each category.
26. Repeat Customers: Find customers who placed more than one order.
27. Revenue Contribution: Calculate each product category's percentage contribution to total revenue.
28. Order Cancellation Rate: Calculate the percentage of orders that were cancelled.
29. Business Performance Summary: Create a report showing total orders, total revenue, average order value, top-selling product, and highest-revenue city.

## Key Learning
Practiced writing SQL queries to clean, combine, and analyze retail sales data to answer business questions.
